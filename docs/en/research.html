Reinforcement Learning · Graph Neural Networks

2021 · Undergraduate research student

Example of re-running pathfinding

A graph model for generating TSP routes using reinforcement learning

We implemented a search program that represents cities as a graph and uses reinforcement learning to select which city to add to the route.

Reinforcement learningStructure2VecQ-learningGraph neural networkTensorFlow

Tasks performed

Based on the graph representations and Q-learning concepts from the referenced paper, I implemented experimental code that connects the TSP environment, model, training loop, and insertion rules.

Results

The program takes city locations, distances, and visitation status as graph inputs, and uses an insertion heuristic to add the model-selected city to the route. During the re-execution of publicly available code, we also investigated why the learning process was not performing as expected compared to the baseline.

  • Step 2 AI city selection + heuristic route insertion

Computer vision · Image classification

2021 · Undergraduate research student

Fashion-MNIST prediction example

A model for classifying clothing photos with ResNet

We learned to divide K-Fashion clothing photos into dresses, outerwear, pants, and tops, and analyzed errors for each class.

TensorFlowResNet50V2Class imbalanceError analysis

Tasks performed

Implemented code for clothing classification using a pre-trained ResNet50V2 model, along with a workflow for class-based sampling and evaluation; misclassifications were analyzed using a confusion matrix.

Results

We created a learning and analysis pipeline that classifies K-Fashion photos into dresses, outerwear, pants, and tops. Afterwards, we changed the settings of the public code one by one from the alternative data to separately check the impact of data augmentation and shortcut connection on the prediction.

  • 4 types Classification: Dresses, outerwear, pants, and tops

Computer vision · Virtual try-on

2021 · Undergraduate research student

Example of preprocessing for pose/human body parsing

Virtual Try-On App for Clothing on Photos of People

We created a flow in the Android app where when you select a portrait and an outfit to wear, the server returns a virtual wearing image.

PyTorchVirtual try-onHuman parsingFlaskAndroid

Tasks performed

Configured input preprocessing and clothing masks for a virtual try-on model; integrated a Flask upload API with an Android client built using Kotlin and Retrofit.

Results

We developed an integrated workflow that takes a person's photo and a selected garment, performs preprocessing, generates an image of the person wearing the item, and returns the result to the app. We reused existing generative models as well as pose and body-parsing models; our own implementation focused on input configuration, mask processing, and the integration between the server and the app.

  • Step 3 Pre-processing → Generate "try-on" image → Return to app
