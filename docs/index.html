무료 웹캐드와 3D 뷰어, 오픈캐드

모든 도구와 사용 안내

DWG·DXF 도면을 열고 고쳐 저장하는 2D 캐드, STEP·SketchUp 모델과 NC 공구 경로를 보는 뷰어를 만들고 있습니다. 모두 설치 없이 무료로 쓰는 개인 오픈소스 프로젝트이고, 뷰어들이 함께 쓰는 3D 코어도 공개했습니다.

무료 웹캐드 시작하기
  1. 2D 도면OpenCAD DWG·DXF설치나 회원가입 없이 DWG·DXF 도면을 열고, 새로 그리거나 편집한 뒤 저장하는 무료 웹캐드입니다. 거리·각도·면적 측정과 PDF·PNG·SVG 출력도 지원합니다..dwg.dxf
  2. 3D CAD 부품·조립 모델OpenCAD STEP 뷰어STEP·STP 3D CAD 파일을 설치 없이 브라우저에서 여는 무료 뷰어입니다. 조립 구조와 부품 속성을 확인하고, 구멍 지름과 면 사이 거리를 재며, 단면과 분해 보기로 안쪽까지 살펴봅니다..step.stp.p21
  3. SketchUp 3D 모델OpenCAD SketchUp 뷰어SketchUp 6~2026에서 저장한 SKP 파일을 브라우저에서 여는 무료 뷰어입니다. 태그·재질과 그룹·컴포넌트를 살펴보고, 장면 재생과 걷기로 공간을 둘러보며 거리와 각도를 잽니다..skp
  4. G-code·Heidenhain·MPR·PGI·XMLOpenCAD NC 뷰어G-code와 Heidenhain(평문, DIN/ISO), 판재 가공 파일(woodWOP MPR, WangShi PGI, KDT XML)의 3D 공구 경로를 확인하는 무료 NC 뷰어입니다. 코드 줄과 이동을 함께 짚고 가공 순서를 재생하며, 장비에 넣기 전에 확인할 줄을 경고로 알려 줍니다..nc.gcode.ngc.h.mpr.pgi.xml
개발자를 위한 WebGL2 라이브러리OpenCAD 3D 뷰어 코어NC·STEP·SKP 뷰어가 함께 쓰는 WebGL2 3D 뷰어 라이브러리입니다. 해석기가 넘긴 장면을 화면에 그리고, 선택과 측정을 맡습니다.

  1. 강화학습 · 그래프 신경망 · 경로 탐색 예시강화학습으로 TSP 경로를 만드는 그래프 모델도시를 그래프로 표현하고, 경로에 추가할 도시를 강화학습으로 고르는 탐색 프로그램을 구현했습니다.담당그래프 환경·학습 루프와 도시 삽입 규칙을 연결했습니다.2단계AI 도시 선택 + 휴리스틱 경로 삽입
  2. 컴퓨터 비전 · 이미지 분류 · Fashion-MNIST 예측 예시ResNet으로 의류 사진을 분류하는 모델K-Fashion 의류 사진을 드레스, 아우터, 바지, 상의로 나누도록 학습하고 클래스별 오류를 분석했습니다.담당전이학습·클래스별 샘플링·혼동행렬 평가를 구현했습니다.4종드레스 · 아우터 · 바지 · 상의 분류
  3. 컴퓨터 비전 · 가상 착용 · 포즈·인체 파싱 전처리 예시인물 사진에 옷을 입혀 보는 가상 착용 앱인물 사진과 입힐 옷을 고르면 서버가 가상 착용 이미지를 돌려주는 Android 앱과 서버를 만들었습니다.담당공개 모델의 입력 전처리와 Flask API·Android 앱을 연결했습니다.3단계전처리 → 착용 이미지 생성 → 앱 반환
