3D加工特徴認識をFusion CAMオートメーションに接続する際に確認したもの

加工特徴認識AIの平均スコアが向上したからといって、CAM工程が正しく作成されるとは限りません。これまでの研究開発事例に基づき、形状認識、工程生成、結果検証の各段階において、どのような点を確認したかをまとめます。

本稿で確認する内容
  1. CADの面と接続関係をAI入力にする
  2. 平均スコアと、部品全体のエラーを併せて確認します
  3. 認識結果を実行可能なCAM操作へとつなげます
  4. 協力機関のシミュレーション結果を可視化します

CADの面と接続関係をAI入力にする

STEPモデルで面・エッジと曲面種類を読み、当たった面の凸・凹関係をグラフで表現しました。ポケットや穴など、複数の面が一緒にする特徴を扱うには、個々の面の形状だけでなく、接続関係も必要です。

担当した範囲は、形状分析、学習用ラベリングプログラム、加工特徴認識AI、加工戦略の設計、およびFusionへの適用です。デジタルツイン（MDT）においては、韓国機械研究院が実施したシミュレーション結果の可視化のみを担当しました。

平均スコアと、部品全体のエラーを併せて確認します

面がいくつか誤分類されるだけでも、加工特徴のまとまりが変わってしまいます。面単位の指標に加え、すべての面を正しく分類できた部品の数、クラス別のエラー、部品系列別の結果を確認しました。平均値が向上していても、特定の系列でエラーが増加した候補は採用しませんでした。

ラベルの修正による改善結果と、学習の変更による改善結果を分離しました。入力、データ拡張（オーグメンテーション）、ラベルを一度に変更してしまうと、どの変更が効果的だったのかを説明するのが難しくなるためです。

  • 形状系列を基準として、データの分割と評価範囲を確認します。
  • 学習時に使用した入力データと、推論時の入力データが同一の基準に基づいているかを確認します。
  • STEPを保存した もう一度読んでもラベルが保持されていることを確認します。

認識結果を実行可能なCAM操作へとつなげます

認識結果だけでは加工工程は完成しません。加工方向、クランプ（固定）、工程順序、工具、および切削条件を決定した上で、Fusionのセットアップ・工具・操作へと……接続しました。

工具のみの変更で済む場合と、作業内容を再作成する必要がある場合を区別しました。また、適用、工具変更、エラー復旧の各プロセスについて、自動回帰テスト（リグレッションテスト）を実施して確認を行いました。これは、正常に生成できるかだけでなく、変更後も結果が一貫しているかを確認する工程です。

協力機関のシミュレーション結果を可視化します

AIの基本面分類と形状組み合わせ分析で、ストック・ブラインドホール・スルーホール・オープンポケット・クローズポケット・チャンパー・フィレット・カウンターボア・カウンターシンクの9種を識別します。全体のケースでは、実際の学習用STEPモデル6つのラベルとフィーチャー別Fusion加工経路を紹介します。

デジタルツインシミュレーションは韓国機械研究院が実施したものであり、私は結果ビューアにおける可視化のみを担当しました。この画面では、工程やNC区間ごとに切削力やチップ厚みを確認できるほか、3D上で設計モデルと加工結果を比較することが可能です。公開されている例では、設計に対する公差基準は±0.15mmとなっています。加工面のうねりや形状誤差マップは、それらの出力を含む解析において表示されます。

素材シミュレーションと基準STEPの比較まで確認しました。新規部品の独立評価、実測粗さ、図面公差の読み取り、および実際のCNC加工品質の承認は、検証範囲に含まれていません。
