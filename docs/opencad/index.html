무료 캐드 뷰어로
도면·3D 모델·공구 경로를 엽니다.

OpenCAD는 AI·CAD/CAM 개발자 김규태가 만드는 오픈소스 캐드 프로젝트입니다. DWG·DXF 2D 도면은 무료 2D 캐드에서 열어 보고, 새로 그리거나 고친 뒤 저장할 수 있습니다. STEP·STP 3D 모델, SketchUp SKP 파일과 NC·G-code·MPR 공구 경로는 형식별 무료 뷰어에서 확인하세요. 설치나 회원가입 없이 파일을 브라우저에서 처리합니다.

설치
주소를 열면 바로 씁니다.

비용
무료이고, 코드를 MIT 라이선스로 공개합니다.

공개2D 도면

OpenCAD DWG·DXF

.dwg.dxf

DWG·DXF 도면을 열어 보고, 새로 그리거나 고친 뒤 다시 저장하는 무료 2D 캐드입니다. 거리·각도·면적을 재고 PDF·PNG·SVG로 출력할 수도 있습니다.

열기

확인

편집
그리기와 수정 명령, 치수, 해치, 블록
저장
DWG, DXF로 저장하고 PDF, PNG, SVG로 출력
모바일
편집 리본 대신 보기 모드: 거리·반지름·각도·면적 재기와 누른 객체의 치수 정보

측정
두 점 사이 거리 측정과 현재 화면 PNG 저장

공개SketchUp 3D 모델

OpenCAD SketchUp 뷰어

.skp

SketchUp 2021~2026에서 저장한 SKP 파일을 브라우저에서 여는 무료 뷰어입니다. 태그·재질과 그룹·컴포넌트를 살펴보고 거리를 측정할 수 있습니다.

형식
SketchUp 2021~2026에서 저장한 .skp 파일. 2020 이하 버전 파일은 아직 열지 못합니다.
탐색
태그 켜고 끄기, 재질 확인, 그룹·컴포넌트 선택과 숨기기
보기
표준 뷰, 원근·평행 투영, 음영·모서리·와이어프레임·X-ray
측정
두 점 사이 거리·축별 차이 확인과 PNG 저장
모바일
보기·측정 단추만 한 줄에 두고, 측정 막대와 줄자·각도기 길게 눌러 정밀 조준

뷰어를 연결하는 오픈소스 코어

  • 개발자를 위한 WebGL2 라이브러리

    OpenCAD 3D 뷰어 코어

    NC·STEP·SKP 뷰어가 함께 사용하는 WebGL2 기반 3D 뷰어 라이브러리입니다. 해석기가 만든 장면을 받아 표시·선택·측정하는 공통 기능을 제공합니다.

캐드 뷰어 사용 안내

  • .dwg.dxf

    DWG·DXF 파일을 무료 캐드 뷰어로 여는 방법

    설치·회원가입 없이 OpenCAD에서 DWG·DXF 도면을 여는 방법입니다. 지원 버전, 파일 열기, 도면층과 글꼴 확인, 열리지 않는 파일을 점검하는 순서를 안내합니다.

  • .dwg.dxf

    캐드 도면 거리·면적 측정과 PDF 출력 방법

    OpenCAD에서 DWG·DXF 도면의 거리와 면적을 측정하고 PDF로 출력하는 방법입니다. DIST·AREA 명령, 객체 스냅, 단위 확인과 플롯 축척 점검을 안내합니다.

  • .step.stp.p21

    STEP·STP 파일 열기와 빈 화면·누락 형상 점검 방법

    무료 OpenCAD STEP 뷰어에서 STP·STEP 파일을 여는 방법입니다. 예제 조립 모델, 압축 파일 지원, 전체 보기·부품 표시와 해석 경고를 확인하는 순서를 안내합니다.

  • .skp

    SKP 파일 무료로 열기와 SketchUp 버전·누락 객체 점검

    OpenCAD SKP 뷰어에서 SketchUp 파일을 여는 방법입니다. 지원 저장 버전, 태그·구성·재질 확인과 일부만 읽힌 모델의 경고를 점검합니다.

  • .nc.gcode.ngc.h.mpr.pgi.xml

    NC·G-code 공구 경로 보기와 단위·해석 경고 점검

    무료 OpenCAD NC 뷰어에서 G-code와 Heidenhain, 판재 가공 파일(MPR, PGI, XML)의 공구 경로를 확인하는 방법입니다. 예제 재생, 코드 줄 연결, 방언·단위와 해석 경고를 점검합니다.

열리지 않는 도면이나 먼저 지원했으면 하는 형식이 있으면 GitHub 이슈나 메일로 알려 주세요.
