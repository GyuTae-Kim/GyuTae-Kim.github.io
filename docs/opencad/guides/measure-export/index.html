캐드 도면 거리·면적 측정과 PDF 출력 방법

도면의 치수 문자와 실제 형상 크기는 다를 수 있습니다. 객체의 좌표를 기준으로 재고, 도면 단위를 확인한 뒤 출력 축척을 정하는 순서로 작업합니다.

무료 DWG·DXF 뷰어 열기
이 글에서 확인할 내용
  1. 측정 전에 도면 단위를 확인합니다
  2. 두 점 사이의 거리를 잽니다
  3. 면적과 객체 특성을 확인합니다
  4. PDF로 출력하고 축척을 확인합니다

측정 전에 도면 단위를 확인합니다

DWG·DXF 좌표의 1이 언제나 1mm를 뜻하는 것은 아닙니다. 원본 도면의 단위 설정과 알고 있는 기준 길이를 대조하세요. 단위 정보가 없거나 잘못된 파일은 측정값만으로 실제 크기를 확정할 수 없습니다.

치수 문자가 수동으로 바뀐 도면도 있습니다. 표시 문자만 읽기보다 실제 형상을 측정하고, 필요하면 치수 목록에서 표시 문자와 실제 측정값을 나란히 확인하세요.

두 점 사이의 거리를 잽니다

명령행에 DIST 또는 별칭 DI를 입력하고 Enter를 누르면 두 점의 거리를 잴 수 있습니다. MEASUREGEOM(별칭 MEA)에서도 거리·반지름·각도·면적을 선택할 수 있습니다.

  1. 뷰어에서 도면을 열고 측정할 부분을 충분히 확대합니다.
  2. 객체 스냅을 켭니다(F3). 끝점·중간점·중심 등 목적에 맞는 스냅으로 정확한 점을 지정하세요.
  3. DIST를 실행하고 첫 번째 점과 두 번째 점을 차례로 선택합니다.
  4. 명령행에 나온 측정값을 읽고 도면 단위와 기준 길이에 맞는지 확인합니다. Esc로 진행 중인 명령을 종료할 수 있습니다.

면적과 객체 특성을 확인합니다

AREA 또는 AA를 실행해 명령행 안내에 따라 경계점을 지정하거나 지원되는 객체를 선택합니다. 면적은 도면 단위의 제곱으로 해석해야 합니다. 예를 들어 좌표 단위가 mm라면 면적의 단위는 mm²입니다.

닫힌 경계를 재는지, 구멍이나 제외할 영역이 있는지 확인하세요. 열린 선이나 잘못 연결된 경계를 눈대중으로 합쳐 계산하면 원하는 면적과 달라질 수 있습니다. 객체 특성에 표시되는 길이·면적도 함께 비교할 수 있습니다.

PDF로 출력하고 축척을 확인합니다

PLOT(별칭 PRINT·EXPORTPDF)은 플롯 설정을 열어 PDF로 출력합니다. 출력은 도면을 PDF로 표현하는 작업이며, DWG·DXF 원본 편집 데이터의 저장과는 구분됩니다.

  1. 모형 또는 출력할 배치 탭을 선택하고 PLOT을 실행합니다.
  2. 용지 크기, 출력 영역과 축척을 정합니다. 흑백·회색조와 선가중치도 필요한 기준에 맞춥니다.
  3. 미리보기에서 잘린 부분, 문자, 선 두께를 확인한 뒤 PDF를 저장합니다.
  4. 실제 크기가 필요한 출력은 알려진 길이와 용지 크기를 다시 확인합니다. 종이 인쇄 시 PDF 인쇄 창의 「페이지에 맞춤」 설정도 점검하세요.
  • 모든 배치를 한 PDF로 내보내는 기능도 지원합니다.
  • 수정한 도면은 다른 이름으로 DWG·DXF 저장해 원본과 비교할 수 있습니다.
  • 측정과 화면 출력만으로 실제 가공 품질이나 장비 투입 안전성이 확인되는 것은 아닙니다.
