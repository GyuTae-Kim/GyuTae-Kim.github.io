무료 온라인 스케치업 뷰어로 SKP 파일 열기

전체 기능과 지원 범위

SketchUp Viewer 다운로드가 중단된 뒤 쓸 방법

SketchUp 공식 안내에 따르면 2025년 4월 22일부터 데스크톱 뷰어의 신규 다운로드가 중단됐습니다. 공식 공유 대안과 로컬 파일 뷰어 중 작업에 맞는 방식을 선택하세요.

  • 로컬 SKP 파일 보기: OpenCAD에서 파일을 선택해 태그·장면·치수를 확인합니다. 모델 파일을 서버에 업로드하지 않습니다.
  • 링크로 모델 공유: SketchUp 공식 Trimble Connect·Link Sharing 안내를 확인합니다.
  • 가구 모델 편집: SketchUp 같은 모델링 도구가 필요합니다. OpenCAD SKP 뷰어는 보기 전용입니다.

SketchUp 저장 버전 확인

현재 OpenCAD SKP 뷰어는 SketchUp 6, 7, 8과 2013~2026에서 저장한 .skp 파일을 엽니다. SketchUp 3~5에서 저장한 아주 옛 파일은 읽지 못하고, 열면 저장 버전을 알려 줍니다. 확장자만 .skp로 바꾸어도 지원되는 파일로 변환되지 않습니다.

OpenCAD는 SketchUp 공식 제품이 아닙니다. 지원하지 않는 버전이라면 파일을 보낸 사람에게 SketchUp 6 이상에서 다시 저장해 달라고 요청하세요.

예제와 내 모델을 여는 순서

「예제로 먼저 보기」에서는 이 브라우저에서 만든 집 모형이 열립니다. 여기서 태그·재질·구성 패널과 전체 보기를 먼저 익힙니다.

  1. 「열기」에서 .skp 파일을 선택하거나 창 안에 끌어다 놓습니다.
  2. 모델이 열리면 「전체 보기」 또는 F로 화면에 맞춥니다.
  3. 태그·재질 패널에서 표시 상태를, 구성 패널에서 그룹·컴포넌트 관계를 확인합니다.
  4. 정보 패널에서 저장 버전, 단위, 해석 경고와 일부만 읽혔다는 안내가 있는지 확인합니다.

일부 객체나 재질이 안 보일 때

태그와 구성 항목이 꺼져 있는지 먼저 확인하세요. 「숨긴 형상 보기」 설정과 단면 설정도 살펴보고, 선택한 그룹을 확대해 전체 모델과 비교합니다.

재질은 파일 안의 무늬 그림을 읽어 표시하지만, 일부 재질과 객체는 원본과 다르게 보일 수 있으니 원본 프로그램의 같은 장면과 비교해 보세요. 장면 탭을 누르면 그 장면에 저장된 카메라, 숨긴 태그, 단면과 스타일로 바뀝니다.

일부만 읽혔다는 경고가 나온다면

끝이 잘렸거나 내부 데이터 길이가 깨진 파일은 읽을 수 있는 부분만 표시합니다. 큰 모델도 처리 한도에 도달하면 안내가 나옵니다. 형상이 보여도 모델 전체를 읽었다는 뜻은 아닙니다.

새 파일을 열지 못하면 이전 모델이 남아 있을 수 있으니 화면의 문서 이름과 경고를 확인합니다. 원본이 SketchUp에서 제대로 열리는지 파일을 보낸 사람에게 확인하고, 오류를 알릴 때는 저장 버전과 브라우저, 경고 문구, 공유할 수 있는 작은 예제를 보내 주세요.

모델은 이 기기의 브라우저에서 처리합니다. 공개 이슈에 고객 모델이나 기밀 파일을 첨부하지 마세요.
