전체 기능과 지원 범위

Mac에서 DWG를 열거나 AutoCAD 없이 도면을 보려면

OpenCAD는 별도 CAD 설치나 회원가입 없이 최신 브라우저에서 DWG·DXF 도면을 엽니다. Windows와 macOS에서 JavaScript와 WebGL2를 지원하는 브라우저로 예제를 먼저 확인하세요. 파일 크기와 복잡도에 따라 기기의 메모리와 처리 시간이 달라집니다.

Autodesk DWG TrueView는 Windows용입니다. Mac에서 브라우저 뷰어를 쓸 때는 보기만 하면 되는지, 편집이나 변환까지 필요한지, 파일이 서버에 올라가는지부터 확인하세요.

파일 형식과 지원 버전

DWG는 CAD 도면을 저장하는 형식이고, DXF는 도면 데이터를 다른 프로그램과 주고받을 때 쓰는 형식입니다. 확장자만 바꿔서는 서로 변환되지 않습니다.

OpenCAD는 DWG R13~R2018과 DXF R12~R2018의 ASCII·이진 파일을 읽습니다. 지원 버전이어도 일부 객체, 외부 참조나 글꼴은 원본 프로그램과 다르게 보일 수 있습니다.

파일을 열고 화면을 맞추는 순서

최신 Chrome, Edge, Firefox, Safari 등 JavaScript와 WebGL2를 지원하는 브라우저를 사용하세요.

  1. 아래의 「무료 DWG·DXF 캐드 열기」를 누릅니다. 파일이 없으면 시작 화면의 「예제 도면 열기」로 먼저 둘러봅니다.
  2. 「파일 열기」에서 .dwg 또는 .dxf 파일을 고르거나, 파일을 뷰어 화면에 끌어다 놓습니다.
  3. 도면이 열리면 휠로 확대·축소하고 가운데 버튼을 누른 채 이동합니다. 전체 보기로 도면의 위치를 먼저 확인하세요.
  4. 모형·배치 탭을 바꾸고 도면층의 켜짐·동결 상태를 확인합니다. 객체를 선택하면 특성에 길이·면적 같은 값이 나옵니다.

화면이 비거나 문자와 외부 참조가 빠졌을 때

도면 일부가 안 보인다면 전체 보기와 도면층 상태부터 확인하세요. 원본 도면이 별도 DWG·DXF, 이미지, PDF를 참조한다면 그 파일도 필요합니다. 외부 참조 창(XR)에서 폴더나 파일을 골라 연결합니다.

SHX 글꼴 때문에 문자가 다르게 보이면 SHXFONTS로 이 컴퓨터의 글꼴 폴더를 고릅니다. 한글 대체 글꼴은 원본 SHX 글꼴과 모양이 조금 다를 수 있습니다.

계속 열리지 않으면 파일 확장자와 저장 버전, 오류 문구를 확인해 GitHub 이슈에 알려 주세요. 공개 이슈에는 고객 도면이나 기밀 파일 대신 같은 문제가 생기는 작은 예제를 올립니다.

파일 처리와 사용 범위

고른 도면은 이 컴퓨터의 브라우저에서 열고 저장하며, 서버로 올리지 않습니다. 앱과 표시용 글꼴 같은 정적 파일은 웹에서 내려받습니다.

OpenCAD는 MIT 라이선스로 공개한 개인 오픈소스 프로젝트입니다. 납품이나 가공에 쓸 도면은 원본 프로그램에서 작업 기준대로 다시 확인하세요.
