OpenCAD DWG·DXF

설치나 회원가입 없이 DWG·DXF 도면을 열고, 새로 그리거나 편집한 뒤 저장하는 무료 웹캐드입니다. 거리·각도·면적 측정과 PDF·PNG·SVG 출력도 지원합니다.

도구 소개

전달받은 DWG·DXF 도면을 CAD 프로그램 없이 브라우저에서 열고, 필요하면 고쳐서 다시 저장하는 2D 캐드입니다. 화면 배치와 명령 이름, 단축키는 AutoCAD와 같게 만들었습니다. 파일 해석과 장면 준비는 웹 워커에서, 화면 표시는 WebGL2로 처리합니다.

열기
DWG R13~R2018, DXF R12~R2018 파일과 빈 새 도면
확인
거리, 각도, 면적과 질량 특성(MASSPROP) 측정, 도면층, 치수 목록, 문자 찾기
편집
그리기와 수정 명령, 겹친 스냅을 Tab으로 바꿔 고르기, 치수, 해치, 블록, 쓰지 않는 항목 정리(PURGE)
저장
DWG, DXF로 저장하고, 저장 형식에서 빠지는 객체는 저장 전에 알림
출력
PDF, PNG, SVG 출력, 여러 배치를 한 PDF로 묶기(PUBLISH), PDF 안 도면층 켜고 끄기와 문자 검색
모바일
편집 리본 대신 보기 모드: 거리·반지름·각도·면적 재기, 객체 스냅 고르기, 점 좌표와 문자 찾기, 누른 객체의 치수 정보. 홈 화면에 추가하면 인터넷 없이도 열림

처음 사용하는 순서

  1. DWG·DXF 캐드를 열고 시작 화면의 「예제 도면 열기」로 화면 조작을 먼저 익힙니다.
  2. 「파일 열기」(Ctrl+O)로 .dwg·.dxf 파일을 고르거나 창에 끌어다 놓습니다. 빈 도면에서 시작하려면 「새 도면」(Ctrl+N)을 누릅니다.
  3. 휠로 확대·축소하고 가운데 버튼으로 이동합니다. DI(거리), MEA(측정), LA(도면층)처럼 AutoCAD와 같은 명령을 명령행에 입력합니다.
  4. 고친 도면은 DWG나 DXF로 저장합니다. 저장 형식에서 빠지는 객체가 있으면 저장하기 전에 알려 줍니다. 필요하면 PDF·PNG·SVG로 출력합니다.

설치나 회원가입 없이 무료로 씁니다. 파일은 이 기기의 브라우저에서 읽고 그리며, 서버로 올리지 않습니다.

지원 범위와 확인할 점

  • DWG는 R13~R2018을 열고 R2000~R2018로 저장합니다. R2007 도면은 R2004 형식으로 저장됩니다.
  • 외부 참조, 이미지, PDF 언더레이와 SHX 글꼴은 해당 파일을 따로 골라야 원래대로 보입니다. SHX 큰 글꼴 자리의 한글은 Noto Sans KR로 대신 그려 원본과 다르게 보일 수 있습니다.
  • 영역과 3D 솔리드는 모서리 선으로만 그립니다. 영역을 새로 만들거나 합치고 빼는 명령, 동적 블록의 매개변수를 새로 만드는 명령은 대신 쓸 방법만 안내합니다.
  • 모바일 기기에서는 보기와 치수 확인 화면으로 엽니다. 그리기와 저장은 연필 단추로 편집 화면에 들어가거나 컴퓨터에서 하세요.
  • Autodesk와 관계없는 개인 오픈소스 프로젝트입니다. 납품이나 가공에 쓸 도면은 원본 프로그램과 작업 기준으로 다시 확인하세요.

WebGL2와 JavaScript를 지원하는 브라우저를 사용하세요. OpenCAD는 MIT 라이선스로 공개한 개인 오픈소스 프로젝트입니다.

파일 열기와 표시 문제 점검

  • 무료 온라인 뷰어로 Mac·Windows에서 DWG·DXF 도면 열기

    AutoCAD 설치 없이 Mac·Windows에서 DWG·DXF 파일을 여는 방법입니다. 무료 온라인 OpenCAD가 읽는 버전, 도면층과 글꼴 확인, 파일을 서버에 올리지 않는 처리 방식과 PDF 출력을 설명합니다.

  • DWG·DXF를 PDF로 출력하고 도면 치수 재기

    OpenCAD에서 DWG·DXF 도면의 거리와 면적을 측정하고 PDF로 출력하는 방법입니다. DIST·AREA 명령과 객체 스냅으로 재는 법, 단위와 플롯 축척을 확인하는 순서를 설명합니다.
