가구 패널을 인식해 크기 변경을 계산하는 AI

모델 분석 → AI 패널 인식 → 파라미터 관계 수식화 → 제조 데이터 생성

TensorFlowHierarchical CADNet 기반그래프 입력선형회귀BOM·도면

가구 크기를 바꾸면 패널이 규칙대로 함께 움직입니다

  • 15종인식하는 패널 역할
  • 4종패널이 따라 움직이는 설계 값 (크기, 걸레받이 등)
  • 1건공동발명 특허 출원
  1. 1

    패널·접합면 분석

    가구 3D 모델에서 패널마다 크기와 부피를 구하고, 패널끼리 맞닿는 접합면을 찾아 그래프로 만듭니다.

  2. 2

    AI 패널 인식

    그래프 입력으로 측판, 지판, 천판, 뒷판, 찬넬, 걸레받이, 선반, 도어 등 15종 패널을 인식합니다.

  3. 3

    파라미터 관계 수식화

    전체 크기, 걸레받이, 코너장 멍판, 찬넬 크기를 바꿀 때 패널이 움직이는 규칙을 팀과 정리하고, 선형회귀로 수식화합니다.

  4. 4

    제조 데이터 생성

    정해진 가구에 연결 피스와 하드웨어를 배치하고 BOM, 도면, 엣지밴딩을 계산해 제조 가능한 데이터로 만듭니다.

맡은 역할

팀 프로젝트에서 AI 연구를 직접 맡았습니다.

  • 가구 모델의 패널과 접합면 분석
  • 패널 역할 15종을 인식하는 AI
  • 크기 변경 규칙을 선형회귀로 수식화
  • 브라우저에서 계수식만으로 패널 이동

가구 규칙은 팀과 함께 정리했고, 제조 데이터 생성은 팀이 함께 개발했습니다.

핵심 판단
규칙 시뮬레이션을 매번 돌리지 않고, 규칙으로 만든 샘플을 선형회귀로 맞춰 계수식만으로 패널을 움직이게 했습니다.

사내 가구 데이터로 한 연구 · 정확도 수치는 원본 결과 파일이 없어 생략

자세히 · 단계마다 한 일, 문제와 해결, 검증

01단계마다 한 일

  1. 1

    패널·접합면 분석

    • 패널 크기, 체적, 두께 축 계산
    • 면의 면적, 중심, 접촉 관계 추출
    • 패널과 접합면을 잇는 계층 그래프
  2. 2

    AI 패널 인식

    • Hierarchical CADNet 기반 모델과 MLP로 15종 인식
    • 라벨 데이터에서 형상, 라벨, 그래프를 내보내는 도구
    • 형상 계열 단위 교차검증 분할
    • 특징군 제거 실험과 축 교환 점검
  3. 3

    파라미터 관계 수식화

    • 규칙으로 기준값을 흔든 샘플 생성
    • 패널마다 위치와 크기를 선형회귀로 맞춤
    • 브라우저에서 계수식만으로 패널 이동

    가구 규칙은 팀과 함께 정리했습니다.

  4. 4

    제조 데이터 생성

    • 연결 피스 위치와 하드웨어 배치
    • BOM, 도면, 엣지밴딩 계산

02문제와 해결

  1. 문제크기와 모양이 비슷해도 패널마다 가구 안에서 맡는 역할이 다릅니다.

    해결패널이 어디에 어떻게 맞닿는지를 그래프로 넣어 역할을 인식했습니다.

  2. 문제비슷한 변형 가구가 학습과 평가에 섞이면 점수를 믿기 어렵습니다.

    해결원본 이름으로 형상 계열을 묶어 같은 분할에 넣었습니다.

  3. 문제바뀌지 않아야 할 값까지 회귀식이 건드릴 수 있습니다.

    해결값이 변하지 않는 출력은 계수를 0으로 고정했습니다.

03검증

검증한 것

  • 형상 계열별 교차검증
  • 특징군을 빼 가며 비교한 실험
  • 좌표축을 바꾼 입력의 스트레스 평가
  • 패널 단위 지표
  • 파라미터를 바꾼 뒤 패널 위치 회귀 테스트 (하부 코너장 등)

범위 밖

  • 정확도와 개선율 수치 (원본 결과 파일 없음)
  • 새 가구로 한 외부 검증
  • 좌표가 바뀌어도 늘 같은 예측

남아 있는 코드와 연구 노트로 정리했습니다. 관련 특허는 공동발명으로 출원된 상태이고, 이 구현이 청구항을 그대로 옮긴 것은 아닙니다.
