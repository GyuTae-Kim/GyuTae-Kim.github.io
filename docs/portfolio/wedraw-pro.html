Wedraw Pro, 가구 설계에서 생산까지

디자이너는 가구빌더로 설계하고, 제조 담당자는 커넥터로 생산 데이터를 받습니다

SketchUp Ruby APIJavaScriptPythonMPR·PGI네스팅

디자이너의 설계가 공장의 가공 데이터가 됩니다

  • 166개데모 주방 한 채의 부품
  • 22장네스팅한 원장 · 수율 76.5%
  • 4종BOM, 라벨, 가공 도면, 가공 코드를 한 번에
  1. 1

    가구빌더로 설계

    디자이너가 SketchUp 안의 가구빌더로 몸통, 도어, 하드웨어, 마감재와 결 방향을 정해 가구를 설계합니다.

  2. 2

    도면과 발주

    플로터가 평면, 입면, 내부 도면을 만들고, 커넥터의 발주 모드에서 견적과 발주 상담으로 넘어갑니다.

  3. 3

    커넥터로 제조 데이터

    제조 담당자가 커넥터에서 도어 결맞춤 그룹과 네스팅을 확인하고 BOM, 라벨, 가공 도면, MPR·PGI 가공 코드를 한 번에 출력합니다.

  4. 4

    생산 투입

    네스팅과 가공 코드를 현장 CNC로 넘기기 전에 웹 네스팅 뷰어와 NC 뷰어로 확인하고, 라벨을 붙여 생산합니다.

맡은 역할

팀과 함께 개발하는 제품입니다. 제조 데이터 출력과 생산 투입을 리딩했고, 도면과 발주는 초기 개발을 리딩했습니다.

  • 커넥터 제조 모드와 출력 (BOM, 라벨, 가공 도면, MPR·PGI)
  • 도어 결맞춤 그룹 편집과 판재 회전 시 가공 위치 유지
  • 네스팅 웹 뷰어와 NC 뷰어로 생산 전 확인
  • 플로터 도면과 커넥터 발주 모드 초기 개발

설계 도구인 가구빌더는 팀이 함께 개발했습니다.

핵심 판단
네스팅기와 스키퍼의 투입 방향, 공구 위치, 찬넬 가공 순서처럼 현장에서 쌓인 가공 노하우를 가공 파일 출력 규칙에 담았습니다. 판재를 돌리거나 뒤집어도 가공 위치, 엣지밴드, 결 방향이 함께 따라갑니다.

제품 화면은 데모·테스트 데이터 · 실제 고객 프로젝트 제외

3D개념 모델로 보는 과정

가구빌더 기본값과 엔진의 네스팅 결과로 그린 원룸 벽면 가구입니다. 설계, 제조, 조립과 설치를 차례로 보여 줍니다.

자세히 · 단계마다 한 일, 문제와 해결, 검증

01단계마다 한 일

  1. 1

    가구빌더로 설계

    디자이너가 SketchUp에서 쓰는 설계 도구입니다.

  2. 2

    도면과 발주

    • 플로터로 평면, 입면, 내부 도면 생성
    • 커넥터 발주 모드 (견적, 발주 상담)
  3. 3

    커넥터로 제조 데이터

    • 제조 모드와 출력 (BOM, 라벨, 가공 도면, MPR·PGI)
    • 경첩, 런너, 리프트 가공을 판재에 투영
    • 도어 결맞춤 그룹 편집과 원장 초과 안내
    • 판재를 돌려도 가공 위치와 엣지밴드 유지
  4. 4

    생산 투입

    • 네스팅 웹 뷰어 (원장 배치, 도어 결맞춤 그룹)
    • NC 뷰어로 가공 코드 확인
    • 2D CAD 웹 뷰어

02문제와 해결

  1. 문제도어 결맞춤을 하려면 한 가구의 도어를 한 원장에서 정면 순서대로 잘라야 하는데, 가공 파일만으로는 어떤 도어끼리 한 그룹인지 알 수 없습니다.

    해결도어 결맞춤 그룹과 정면 위치(A-1, A-2…)를 가공 파일에 실었습니다. 원장보다 큰 그룹은 원장에 맞게 나눕니다.

  2. 문제네스팅기는 원장에 놓인 방향대로 자르고 스키퍼는 톱, 클램프, 찬넬 위치에 맞는 방향으로 넣어야 해서, 가공 파일 하나로는 두 기계를 모두 맞출 수 없습니다.

    해결네스팅기 기준과 스키퍼 기준 가공 파일을 따로 만들고, 스키퍼에 넣는 방향은 라벨의 뒤집기 표시와 투입 화살표로 알려 줍니다.

  3. 문제경첩 컵 구멍은 도어 뒷면에 내야 하는데, 스키퍼의 도어컵 공구는 위쪽에만 있습니다.

    해결도어 가공 전체를 좌우와 가공 면까지 뒤집어 위쪽 공구로 컵 구멍과 유도 보링을 냅니다. 작업자는 라벨 표시대로 도어를 뒤집어 넣습니다.

  4. 문제측판 찬넬(손잡이 홈)을 한 번에 관통하면 공구가 빠져나가는 쪽 엣지밴드가 깨질 수 있습니다.

    해결엣지밴드 파손이 가장 적은 시험 가공 방식을 가공 전략에 녹여냈습니다.

03검증

검증한 것

  • 도어 결맞춤 그룹 편집 8가지를 설계 데이터부터 가공 파일까지 따라가며 대조
  • 실제 설계 데이터(가구 5개, 판재 66장)의 출력을 따로 계산한 회전 결과와 비교
  • 출력 파일과 뒤집기 표시만으로 원래 가공 위치를 되살려 설계와 대조
  • 생성한 가공 파일을 다시 읽어 도어컵과 찬넬의 가공 면, 깊이, 순서 확인

범위 밖

  • 외부 네스팅기가 도어 결맞춤 그룹을 실제로 한 장에 놓는지
  • 현장 기계 설정과 작업자 투입
  • 실제 CNC 가공
