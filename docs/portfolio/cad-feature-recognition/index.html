3D 모델을 읽고 가공 전략까지 설계하는 AI

형상 분석 → AI 가공 특징 인식 → 가공 전략 설계 → 디지털 트윈 검증으로 이어지는 Fusion CAM 자동화

PythonOpenCascadeTensorFlowAutodesk Fusion APICAM

3D 모델에서 가공 특징을 찾아 Fusion CAM 공정을 자동으로 만듭니다

  • 9종식별하는 가공 피쳐 · 스톡 포함
  • ±0.15 mm설계 대비 공차 · MDT 예시의 과삭 판정 기준
  • 1건라벨링 프로그램 등록 신청 접수
  1. 1

    형상 분석

    3D 모델(STEP)의 면과 엣지를 읽어 곡면 종류와 볼록·오목 연결 같은 관계를 그래프로 만듭니다.

  2. 2

    AI 가공 특징 인식

    그래프 신경망의 면 분류와 형상 조합 분석으로 스톡·홀·포켓·챔퍼·필렛 등 9종의 가공 피쳐를 식별합니다.

  3. 3

    가공 전략 설계

    가공 방향, 클램핑, 공정 순서, 공구, 절삭 조건을 정하고 조도 목표에 맞춰 경로 공차를 조정해 Fusion CAM 공정으로 만듭니다.

  4. 4

    디지털 트윈 검증

    협력 기관의 MDT 시뮬레이션 결과를 연동해 절삭력·칩 두께를 그래프로 살펴보고, 가공 결과와 설계 모델의 차이를 3D로 확인합니다.

맡은 역할

형상 분석부터 가공 전략 설계와 Fusion 적용까지 직접 연구개발했습니다.

  • 3D 모델 형상 분석과 그래프 입력
  • 가공 특징 인식 AI와 학습용 라벨링 프로그램
  • 가공 전략 설계와 Fusion CAM 공정 생성
  • MDT 데이터 연동과 절삭 부하·가공 결과 3D 시각화

디지털 트윈(MDT) 시뮬레이션은 협력 기관이 맡았습니다.

만들어낸 결과
3D CAD의 형상을 읽는 AI, 학습용 라벨링 도구, 가공 전략 설계 엔진, Fusion CAM 연동과 디지털 트윈 결과 시각화를 하나의 흐름으로 연결했습니다. 모델을 받아 가공 특징을 식별하고, 공정을 생성한 뒤 시뮬레이션 결과를 살펴볼 수 있는 제조 소프트웨어를 만들었습니다.

검증은 Fusion·MDT 시뮬레이션까지 · 실제 가공 품질 승인 아님

AI식별하는 가공 피쳐 9종

  • 스톡소재·기준 형상
  • 블라인드홀바닥이 막힌 홀
  • 쓰루홀부품을 관통하는 홀
  • 오픈포켓측면으로 열린 포켓
  • 클로즈포켓둘레가 닫힌 포켓
  • 챔퍼모서리의 모따기
  • 필렛둥글게 연결한 모서리
  • 카운터보어단차가 있는 원통형 홀
  • 카운터싱크입구가 원뿔형인 홀

AI가 면 단위로 기본 7종을 분류하고, 홀·단차·챔퍼의 형상 조합을 분석해 카운터보어와 카운터싱크를 식별합니다. 아래는 실제 학습용 STEP 모델 6개를 정답 라벨로 색칠한 예시입니다.

색상은 위 목록의 기본 피쳐와 같습니다. 학습에 사용한 형상과 라벨을 보여주는 자료이며, 새로운 부품에 대한 예측 정확도를 나타내지는 않습니다.

인식한 피쳐가 실제 공정이 되는 과정

같은 부품의 Fusion CAM 화면입니다. 형상과 가공 목적에 따라 황삭·드릴링·포켓·윤곽 경로를 나누어 생성합니다. 파란 선은 절삭 경로, 노란 선은 경로 사이의 연결·이동을 나타냅니다.

숫자와 3D로 살펴보는 디지털 트윈 결과

공정별 절삭 부하를 시간축으로 보고, 시뮬레이션으로 가공된 소재를 설계 모델과 겹쳐 확인하는 결과 뷰어를 개발했습니다. 아래 화면은 보관된 MDT 분석 결과를 불러온 예시입니다.

이 기술로 기대하는 변화

반복 작업을 줄이는 공정 설계

면과 홀을 하나씩 선택하고 공정을 설정하는 반복 작업을 줄여, 숙련자가 공구 선택과 가공 조건 검토에 더 집중할 수 있을 것으로 기대합니다.

제조 지식에 대한 접근성

숙련자의 형상 해석과 공정 설계 절차를 소프트웨어로 축적해, CAM 경험이 적은 작업자와 소규모 제조 현장의 기술 활용을 도울 수 있습니다.

가상 검증을 통한 자원 절약

실제 가공 전에 절삭 부하와 설계 대비 편차를 살펴보는 흐름은 시행착오로 소모되는 소재·공구·시간을 줄이는 기반이 될 수 있습니다.

위 내용은 기술 활용에 대한 기대 효과입니다. 현장 도입에 따른 시간·비용 절감량은 별도 실증이 필요합니다.

3D개념 모델로 보는 과정

실제 엔진이 이 부품에 짜는 공정 순서와 공구로 그린 개념 모델입니다. 모델링, 특징 인식, 바이스 가공을 차례로 보여 줍니다.

자세히 · 단계마다 한 일, 문제와 해결, 검증

01단계마다 한 일

  1. 1

    형상 분석

    • STEP의 면, 엣지, 곡면 종류 추출
    • 맞닿은 면의 볼록, 오목 관계를 그래프로
    • 면과 삼각면을 묶은 계층 그래프 입력
  2. 2

    AI 가공 특징 인식

    • 학습 데이터를 만드는 라벨링 프로그램
    • 형상 계열 기준 데이터 분할
    • 포켓, 필렛, 챔퍼가 헷갈리는 합성 형상
    • 입력, 증강, 라벨 변경별 영향 비교
  3. 3

    가공 전략 설계

    • 면 예측을 가공 특징 그룹으로 정리
    • 가공 방향, 셋업, 공정 순서, 공구, 절삭 조건 결정
    • 조도 목표에 맞춘 경로 공차와 이송
    • Fusion API로 셋업과 공정 생성
    • 공구를 바꾸거나 적용이 실패해도 기존 작업 유지
  4. 4

    디지털 트윈 검증

    • MDT로 넘기는 데이터와 사전 검사
    • 공정·NC 구간별 절삭력과 칩 두께 그래프
    • 최댓값·평균·P95와 해당 시점의 공구·이송·회전수 확인
    • 가공 결과의 설계 대비 편차·가공면 파상도·형상 오차 시각화

    시뮬레이션은 협력 기관이 맡았습니다.

02문제와 해결

  1. 문제면 몇 개만 틀려도 가공 특징 묶음이 달라집니다.

    해결면 단위 점수와 함께 모든 면을 맞힌 부품 수도 셌습니다.

  2. 문제점수가 바뀐 이유가 라벨 수정인지 학습인지 섞여 있었습니다.

    해결라벨을 고쳐서 바뀐 점수와 학습으로 바뀐 점수를 따로 계산했습니다.

  3. 문제인식 결과가 Fusion의 셋업, 공구, 작업과 맞물려야 공정이 됩니다.

    해결공구만 바꾸면 되는 경우와 작업을 새로 만들어야 하는 경우를 나눴습니다.

03검증

검증한 것

  • STEP으로 저장했다 다시 읽어도 라벨 유지
  • 계열별 분할과 학습, 추론 입력 일치
  • 평균 지표, 클래스별 오류, 전부 맞은 부품 수
  • Fusion 자동 회귀 테스트 (적용, 공구 변경, 오류 복구)
  • 소재 시뮬레이션과 기준 STEP 비교
  • MDT 결과의 절삭력·칩 두께 그래프와 설계 대비 3D 비교

범위 밖

  • 새 부품으로 한 독립 평가
  • 실측 조도 (목표값으로 경로 공차와 이송만 조정)
  • 도면 공차 읽기
  • 실제 CNC 가공 품질 승인
