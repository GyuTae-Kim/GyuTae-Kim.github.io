读取 3D 模型并设计处理策略的 AI

Fusion CAM自动化流程：从形状分析 → AI加工特征识别 → 加工策略设计 → 数字孪生结果可视化

PythonOpenCascadeTensorFlowAutodesk Fusion APICAM

在 3D 模型中查找加工特征并自动创建 Fusion CAM 流程

  • 9种识别加工特征 · 包含毛坯
  • ±0.15 mm设计与公差 · MDT 示例中的超切标准
  • 1 例接收标签程序注册申请
  1. 1

    形状分析

    读取 3D 模型的面和边 (STEP)，并创建关系图，例如曲面类型和凸/凹连接。

  2. 2

    AI处理特征识别

    通过图神经网络的表面分类和形状组合分析，识别9种加工特征，包括毛坯、孔、凹槽、倒角和圆角。

  3. 3

    设计加工策略

    确定加工方向、夹紧方式、工艺顺序、刀具和切削条件，调整路径公差以匹配表面光洁度目标，并创建 Fusion CAM 工艺流程。

  4. 4

    数字孪生结果可视化

    接收韩国机械材料研究院执行的MDT仿真结果，并创建3D屏幕，显示切削力和切屑厚度曲线图，以及加工结果与设计之间的差异。

此技术预期带来的变更

工艺设计旨在减少重复性工作

通过减少逐个选择面和孔以及设置加工流程的重复性工作，我们希望熟练工人能够将更多精力集中在刀具选择和加工条件审查上。

制造知识的获取

通过将专家的几何分析和工艺设计流程整合到软件中，您可以帮助CAM经验不足的操作人员和小型制造工厂更好地利用技术。

通过虚拟验证节省资源

在实际加工前检查切削载荷和与设计偏差的过程，可以有效减少因反复试验而消耗的材料、刀具和时间。

详情 · 分步操作、问题及解决方案、验证

01每步执行的操作

  1. 1

    形状分析

    • STEP 曲面、边缘和曲面类型提取
    • 将相邻面的凸凹关系表示为图
    • 输入分层图分组面和三角面
  2. 2

    AI处理特征识别

    • 一个用于创建训练数据的标注程序
    • 基于几何序列的数据分割
    • 复合形状，混淆了口袋、圆角和倒角
    • 比较输入、数据增强和标签更改的影响
  3. 3

    设计加工策略

    • 将面预测结果组织成加工特征组
    • 确定加工方向、设置、工艺顺序、刀具和切削条件
    • 路径容差和馈送与照明目标对齐
    • 使用 Fusion API 进行设置和流程创建
    • 即使工具变更或应用程序故障，也要维护现有工作
  4. 4

    数字孪生结果可视化

    • 按工艺/数控部分划分的切削力和切屑厚度图
    • 显示该点的最大值、平均值、P95 值以及刀具、进给量和转数
    • 可视化加工结果与设计值的偏差、表面波纹度和形状误差

    韩国机械材料研究院负责模拟工作，我负责结果的可视化。

02问题及解决方案

  1. 问题即使只有少数面不正确，加工特征的分组也会发生变化。

    已解决。我们还统计了匹配所有面的零件数量以及面单元得分。

  2. 问题分数变化的原因是标签修改和学习的综合因素。

    已解决。我们分别计算了修改标签和学习后分数的变化。

  3. 问题识别结果必须与 Fusion 的设置、刀具和作业相匹配，才能形成加工流程。

    已解决。我们区分了只需更换刀具的情况和需要创建新作业的情况。
