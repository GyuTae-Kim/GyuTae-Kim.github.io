OpenCAD DWG·DXF

无需安装或注册的免费在线CAD编辑器，可打开、新建、编辑和保存DWG、DXF图纸。支持距离、角度、面积测量，以及PDF、PNG、SVG导出。

.dwg.dxf

打开 OpenCAD DWG·DXFGitHub 源代码文件打开与问题排查

工具简介

这是一款 2D CAD，无需 CAD 软件即可在浏览器中打开收到的 DWG·DXF 图纸，并在需要时修改后重新保存。界面布局、命令名称和快捷键与 AutoCAD 保持一致。文件解析和场景准备在 Web Worker 中进行，画面显示使用 WebGL2。

打开
DWG R13–R2018、DXF R12–R2018 文件和空白新图形
确认
测量距离、角度、面积与质量特性（MASSPROP），图层、尺寸列表、文字查找
编辑
绘图与修改命令、按 Tab 键切换重叠的捕捉点、尺寸、填充图案、块、清理未使用项（PURGE）
保存
保存为 DWG、DXF，保存前提示目标格式中会丢失的对象
输出
输出 PDF、PNG、SVG，将多个布局合并为一个 PDF（PUBLISH），可在 PDF 中开关图层并搜索文字
移动端
以查看模式取代编辑功能区：测量距离、半径、角度和面积，选择对象捕捉，查找点坐标和文字，并显示所点对象的尺寸信息。添加到主屏幕后无需联网也能打开

快速入门

  1. 打开 DWG·DXF CAD，先用开始界面的“打开示例图形”熟悉画面操作。
  2. 通过“打开文件”(Ctrl+O)选择 .dwg·.dxf 文件，或将其拖入窗口。要从空白图纸开始，请按“新建图纸”(Ctrl+N)。
  3. 用滚轮缩放，按住中键平移。可以在命令行输入与 AutoCAD 相同的命令，例如 DI(距离)、MEA(测量)、LA(图层)。
  4. 修改后的图纸可保存为 DWG 或 DXF。如果保存格式会丢失某些对象，会在保存前提示。需要时可输出为 PDF·PNG·SVG。

无需安装或注册即可免费使用。文件解析和画面显示均在本设备的浏览器中完成，所选的绘图或模型文件不会上传到服务器。

支持范围与注意事项

  • DWG 可打开 R13~R2018，并以 R2000~R2018 保存。R2007 图纸会以 R2004 格式保存。
  • 外部参照、图像、PDF 参考底图和 SHX 字体需要另外选择相应文件才能按原样显示。SHX 大字体位置的韩文会改用 Noto Sans KR 绘制，可能与原图显示不同。
  • 面域和三维实体只以边线绘制。新建面域或对其合并、相减的命令，以及新建动态块参数的命令，只会提示替代方法。
  • 在移动设备上会以查看和尺寸确认界面打开。绘图和保存请点击铅笔按钮进入编辑界面，或在电脑上进行。
  • 这是与 Autodesk 无关的个人开源项目。用于交付或加工的图纸，请再用原始软件和作业标准核对。

请使用支持 WebGL2 和 JavaScript 的浏览器。OpenCAD 是以 MIT 许可证公开的个人开源项目。
