OpenCAD 3D 查看器核心

这是一个基于 WebGL2 的 3D 查看器库，供 NC、STEP 和 SKP 查看器使用。它提供了接收、显示、选择和测量口译员创建的场景的常用功能。

GitHub 源代码

工具简介

这是 OpenCAD 中的一个常用库，它将文件解析代码与屏幕绘制代码分离。它接受由三角形、线段和点组成的 Scene3d 场景，从而允许在各种格式的查看器中使用相同的操作和测量功能。

显示
WebGL2、阴影、边缘、线框、X 射线、线段、点图
操作
旋转、平移、缩放、触摸控制、立方体视图和标准视图
选择
基于BVH的选择、分组显示、两点测量并保存图片
连接件
与NC·STEP·SKP解释器共享的Scene3d场景格式

开发集成

  1. 检查 GitHub 上的安装/使用示例和 Scene3d 类型。
  2. 将 Viewer3d 连接到屏幕元素并将解释后的场景传递给 setScene。
  3. 完整的使用示例可在 NC·STEP·SKP Viewer 的“打开示例”中找到。

支持范围与注意事项

  • 这是一个开发库，没有单独的网站可以打开文件。请使用相应的文件查看器来查看文件。
  • 本核心未包含文件解析功能，这些功能分别由 NC·STEP·SKP 存储库处理。

使用支持 WebGL2 和 JavaScript 的浏览器。 OpenCAD 是由 Sean Kim 开发的 MIT 许可的开源项目。
