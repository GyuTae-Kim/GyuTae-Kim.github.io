测量前请检查绘图单位

DWG·DXF 坐标中的 1 并不总是表示 1mm。将原始图纸中的单位设置与已知的参考长度进行比较。对于没有或不正确单位信息的文件，仅根据测量无法确定实际大小。

有些图纸的尺寸标注文字已被手动更改。请测量实际形状，而不仅仅是读取显示文字。如有必要，请在尺寸标注列表中并排检查显示文字和实际测量值。

测量两点之间的距离

在命令行输入 DIST 或别名 DI，然后按 Enter 键测量两点之间的距离。您也可以在 MEASUREGEOM（别名 MEA）中选择距离、半径、角度和面积。

  1. 在查看器中打开绘图，并放大到足以测量的区域。
  2. 开启对象捕捉 (F3)。使用合适的捕捉方式（例如端点、中点或中心）指定精确点。
  3. 运行 DIST 并选择第一个点，然后选择第二个点。
  4. 读取命令行显示的测量值，并验证其是否与绘图单位和参考长度相符。您可以按 Esc 键退出当前命令。

检查面积和对象属性

运行 AREA 或 AA 并按照命令行说明指定边界点或选择支持的对象。面积应解释为绘图单位的平方。例如，如果坐标单位为mm，则面积单位为mm²。要加上或减去多个边界，请使用添加（A）和减去（S）；质心和惯性矩可用 MASSPROP 查看。

检查您是否正在测量闭合边界，以及是否存在需要排除的孔洞或区域。如果您仅凭目测合并开放线或错误连接的边界来计算，结果可能与所需面积有所不同。您还可以比较对象属性中显示的长度和面积。

打印为 PDF 并检查比例

PLOT（又名 PRINT·EXPORTPDF）打开绘图设置并将其输出为 PDF。输出是将工程图表达为 PDF 的过程，与将原始编辑数据保存为 DWG/DXF 不同。

  1. 选择“模型”或“布局”选项卡进行输出并运行绘图。
  2. 设置纸张尺寸、输出区域和缩放比例。将黑白/灰度以及线条粗细调整至所需标准。
  3. 请在预览中检查裁剪、文本和线条粗细，然后保存 PDF 文件。
  4. 对于需要实际尺寸的输出，请仔细核对已知长度和纸张尺寸。打印到纸张上时，请同时检查 PDF 打印窗口中的“适应页面大小”设置。
  • 还支持将所有批次导出为单个 PDF 文件的功能。
  • 您可以将修改后的图形另存为 DWG 或 DXF 格式，以便与原始图形进行比较。
  • 仅凭测量和屏幕输出无法验证实际加工质量或设备输入安全性。
