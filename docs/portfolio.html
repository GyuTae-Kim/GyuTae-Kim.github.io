맡은 역할

형상 분석부터 가공 전략 설계와 Fusion 적용까지 직접 연구개발했으며, 디지털 트윈에서는 시뮬레이션 결과 시각화만 담당했습니다. 디지털 트윈(MDT) 시뮬레이션은 한국기계연구원이 담당했습니다. 본인은 제공된 시뮬레이션 결과의 시각화만 맡았습니다.

05

웹 서비스 · 운영 문제 해결

2026

송장 연동에서 반복되던 전송 오류 개선

송장 연동을 감시에 연결 → 실패 알림으로 원인 추적 → 전송과 엑셀 업로드 처리 수정 → 회귀 테스트 32개

TypeScriptPostgreSQLSupabase Edge Functions외부 API 연동

맡은 역할

송장 연동의 실패 기록을 서비스 감시에 연결하고, 알림으로 드러난 전송 오류의 원인을 찾아 전송과 엑셀 업로드 처리를 고쳤습니다. 연동 기능과 송장 등록 화면은 팀원이 만들었고, 화면에서는 전체 전송 건수와 안내만 맞췄습니다.

결과

  • 6주 전체 전송 때마다 반복되던 같은 실패 해결
  • 2회 → 1회 표기만 바뀐 송장의 전송 횟수
