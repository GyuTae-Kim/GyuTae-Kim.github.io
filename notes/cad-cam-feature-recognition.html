제조 소프트웨어 개발 노트 · 김규태 Sean Kim

3D 가공 특징 인식을 Fusion CAM 자동화로 연결할 때 확인한 것

가공 특징 인식 AI의 평균 점수가 좋아져도 CAM 공정이 올바르게 만들어진다는 보장은 없습니다. 기존 연구개발 사례를 바탕으로 형상 인식, 공정 생성, 결과 검증 사이에서 무엇을 확인했는지 정리합니다.

이 글에서 확인할 내용
  1. CAD의 면과 연결 관계를 AI 입력으로 만듭니다
  2. 평균 점수와 부품 전체의 오류를 함께 봅니다
  3. 인식 결과를 실행 가능한 CAM 작업으로 연결합니다
  4. 협력 기관의 시뮬레이션 결과를 시각화합니다

CAD의 면과 연결 관계를 AI 입력으로 만듭니다

STEP 모델에서 면·엣지와 곡면 종류를 읽고 맞닿은 면의 볼록·오목 관계를 그래프로 표현했습니다. 포켓이나 구멍처럼 여러 면이 함께 만드는 특징을 다루려면 개별 면의 모양뿐 아니라 연결 관계도 필요합니다.

직접 맡은 범위는 형상 분석, 학습용 라벨링 프로그램, 가공 특징 인식 AI, 가공 전략 설계와 Fusion 적용입니다. 디지털 트윈(MDT)에서는 한국기계연구원이 수행한 시뮬레이션의 결과 시각화만 담당했습니다.

평균 점수와 부품 전체의 오류를 함께 봅니다

면 몇 개만 잘못 분류해도 가공 특징의 묶음이 달라집니다. 면 단위 지표와 함께 모든 면을 맞힌 부품 수, 클래스별 오류와 부품 계열별 결과를 확인했습니다. 평균이 좋아졌어도 특정 계열의 오류가 늘어난 후보는 채택하지 않았습니다.

라벨을 수정해 좋아진 결과와 학습 변경으로 좋아진 결과도 분리했습니다. 입력·증강·라벨을 한꺼번에 바꾸면 어떤 변경이 효과가 있었는지 설명하기 어렵기 때문입니다.

  • 형상 계열을 기준으로 데이터 분할과 평가 범위를 확인합니다.
  • 학습 때 만든 입력과 추론 입력이 같은 기준인지 확인합니다.
  • STEP을 저장했다 다시 읽어도 라벨이 유지되는지 확인합니다.

인식 결과를 실행 가능한 CAM 작업으로 연결합니다

인식 결과만으로는 가공 공정이 완성되지 않습니다. 가공 방향, 클램핑, 공정 순서, 공구와 절삭 조건을 정한 뒤 Fusion의 셋업·공구·작업으로 연결했습니다.

공구만 바꾸면 되는 경우와 작업을 새로 만들어야 하는 경우를 나눴고, 적용·공구 변경·오류 복구를 자동 회귀 테스트로 확인했습니다. 생성 성공뿐 아니라 변경 후에도 결과가 일관되는지 보는 과정입니다.

협력 기관의 시뮬레이션 결과를 시각화합니다

AI의 기본 면 분류와 형상 조합 분석으로 스톡·블라인드홀·쓰루홀·오픈포켓·클로즈포켓·챔퍼·필렛·카운터보어·카운터싱크의 9종을 식별합니다. 전체 사례에는 실제 학습용 STEP 모델 6개의 라벨과 피쳐별 Fusion 가공 경로를 소개합니다.

디지털 트윈 시뮬레이션은 한국기계연구원이 수행했으며, 본인은 결과 뷰어의 시각화만 담당했습니다. 이 화면에서 절삭력·칩 두께를 공정과 NC 구간별로 살펴보고, 3D에서 설계 모델과 가공 결과를 비교할 수 있습니다. 공개 예시의 설계 대비 공차 기준은 ±0.15mm입니다. 가공면 파상도·형상 오차 맵은 해당 출력을 포함한 분석에서 표시합니다.

소재 시뮬레이션과 기준 STEP 비교까지 확인했습니다. 새 부품의 독립 평가, 실측 조도, 도면 공차 읽기와 실제 CNC 가공 품질 승인은 검증 범위에 포함하지 않았습니다.
