DWG·DXF 파일을 무료 캐드 뷰어로 여는 방법

도면을 전달받았지만 CAD 프로그램이 없을 때, 브라우저에서 OpenCAD를 열어 내용을 확인할 수 있습니다. 먼저 예제 도면으로 화면 조작을 익힌 뒤 실제 파일을 여세요.

먼저 파일 형식과 지원 버전을 확인합니다

DWG는 CAD 도면을 저장하는 형식이고, DXF는 도면 데이터를 다른 프로그램과 주고받을 때 쓰는 형식입니다. 확장자만 바꿔서는 서로 변환되지 않습니다.

OpenCAD는 DWG R13~R2018과 DXF R12~R2018의 ASCII·이진 파일을 읽습니다. 지원 버전이어도 일부 객체, 외부 참조나 글꼴은 원본 프로그램과 다르게 보일 수 있습니다.

파일을 열고 화면을 맞추는 순서

최신 Chrome, Edge, Firefox, Safari 등 JavaScript와 WebGL2를 지원하는 브라우저를 사용하세요.

  1. 아래의 「무료 DWG·DXF 뷰어 열기」를 누릅니다. 파일이 없으면 시작 화면의 「예제 도면 열기」로 먼저 둘러봅니다.
  2. 「파일 열기」에서 .dwg 또는 .dxf 파일을 고르거나, 파일을 뷰어 화면에 끌어다 놓습니다.
  3. 도면이 열리면 휠로 확대·축소하고 가운데 버튼을 누른 채 이동합니다. 전체 보기로 도면의 위치를 먼저 확인하세요.
  4. 모형·배치 탭을 바꾸고 도면층의 켜짐·동결 상태를 확인합니다. 객체를 선택하면 특성에서 길이·면적 등 관련 값을 볼 수 있습니다.

빈 화면, 빠진 문자와 외부 참조를 점검합니다

도면 일부가 안 보인다면 전체 보기와 도면층 상태부터 확인하세요. 원본 도면이 별도 DWG·DXF, 이미지, PDF를 참조한다면 그 파일도 필요합니다. 외부 참조 창(XR)에서 폴더나 파일을 골라 연결할 수 있습니다.

SHX 글꼴 때문에 문자가 다르게 보일 때는 SHXFONTS로 이 컴퓨터의 글꼴 폴더를 선택할 수 있습니다. 한글 대체 글꼴과 원본 SHX 글꼴의 표시가 완전히 같지는 않을 수 있습니다.

계속 열리지 않으면 파일 확장자와 저장 버전, 오류 문구를 확인해 GitHub 이슈에 알려 주세요. 공개 이슈에 고객 도면이나 기밀 파일을 첨부하지 말고, 공유 가능한 최소 예제로 재현해 주세요.

파일 처리와 사용 범위

선택한 도면의 읽기·표시·저장은 이 컴퓨터의 브라우저에서 처리하며 도면 파일을 서버에 업로드하지 않습니다. 앱과 표시용 글꼴 같은 정적 자료는 웹에서 내려받습니다.

OpenCAD는 김규태의 MIT 라이선스 개인 오픈소스 프로젝트입니다. 중요한 납품이나 가공에 사용할 도면은 원본 프로그램 및 작업 기준과 대조해 확인하세요.
