경로 탐색 재실행 예시

강화학습으로 TSP 경로를 만드는 그래프 모델

도시를 그래프로 표현하고, 경로에 추가할 도시를 강화학습으로 고르는 탐색 프로그램을 구현했습니다.

Reinforcement learningStructure2VecQ-learningGraph neural networkTensorFlow

직접 한 일

참고 논문의 그래프 표현과 Q-learning 아이디어를 바탕으로, TSP 환경·모델·학습 루프·삽입 규칙을 연결하는 실험 코드를 구현했습니다.

만들어낸 결과

도시의 위치·거리·방문 상태를 그래프로 입력하고, 모델이 고른 도시를 삽입 휴리스틱으로 경로에 추가하는 탐색 프로그램을 만들었습니다. 공개 코드 재실행에서는 기준선과 비교해 학습이 제대로 작동하지 않는 원인도 추적했습니다.

Fashion-MNIST 예측 예시

ResNet으로 의류 사진을 분류하는 모델

K-Fashion 의류 사진을 드레스, 아우터, 바지, 상의로 나누도록 학습하고 클래스별 오류를 분석했습니다.

TensorFlowResNet50V2Class imbalanceError analysis

직접 한 일

사전학습 ResNet50V2를 이용한 의류 분류 학습 코드와 클래스별 샘플링·평가 흐름을 구현하고, 혼동행렬로 오분류를 분석했습니다.

만들어낸 결과

K-Fashion 사진을 드레스·아우터·바지·상의로 분류하는 학습·분석 파이프라인을 만들었습니다. 이후 공개 코드의 설정을 대체 데이터에서 하나씩 바꿔, 데이터 증강과 숏컷 연결이 예측에 미치는 영향을 분리해 확인했습니다.

인물 사진에 옷을 입혀 보는 가상 착용 앱

Android 앱에서 인물 사진과 입힐 옷을 선택하면, 서버가 가상 착용 이미지를 돌려주는 흐름을 만들었습니다.

PyTorchVirtual try-onHuman parsingFlaskAndroid

직접 한 일

공개 가상 착용 모델에 필요한 입력 전처리와 의류 마스크를 구성하고, Flask 업로드 API와 Kotlin·Retrofit Android 클라이언트를 연결했습니다.
